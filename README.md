# Mutera

Основа игры Mutera — симуляция организмов, геномов, мутаций и эволюции.

## Stage 0

Первый этап создаёт минимальное ядро без обязательных внешних сервисов:

- `src/genome.py` — геном, случайная генерация и мутации.
- `src/organism.py` — организм, энергия, возраст и размножение.
- `config/settings.json` — базовые параметры симуляции.
- `main.py` — локальная точка запуска.
- `tests/` — автоматические проверки ядра.
- `.github/workflows/test.yml` — запуск тестов при push и pull request.

## Запуск

```bash
python main.py
```

## Тесты

```bash
pip install -r requirements-dev.txt
pytest -q
```

Следующий этап может добавить популяцию, наследование признаков, среду и правила естественного отбора.
